A cache keeps frequently requested information close to an application. When the application needs data, the cache can answer without contacting a slower service. This cache improves response time, but temporary entries require careful management. Expiration removes values after a configured lifetime. Eviction creates room when storage reaches its limit. Invalidation removes values when their original source changes. Engineers must choose policies that balance speed, memory use, and freshness. Short lifetimes reduce stale results but increase repeated work. Long lifetimes improve reuse but may return older information. Monitoring hit rates and latency helps teams adjust these choices for real traffic.
